## Five-Dimension Framework

| Dimension | Weight | What It Measures |
|-----------|--------|------------------|
| **Cash Flow Quality** | 45% | Operating cash flow trend, cash runway, debt burden, cash-to-earnings ratio |
| **Profitability** | 20% | Gross/net margins, revenue growth (3Y CAGR), R&D efficiency, revenue per employee |
| **Debt Solvency** | 15% | Debt ratio, interest-bearing debt, current ratio, cash ratio, equity pledge |
| **Operational Efficiency** | 10% | Receivables turnover, customer concentration, headcount trend, management stability |
| **Sustainability** | 10% | Market growth, technical moat, diversification, funding runway, regulatory risk |

**Scoring grades:**

| Range | Label |
|-------|-------|
| 85–100 | 🟢 Excellent |
| 70–85 | 🟡 Moderate-High |
| 55–70 | 🟠 Moderate |
| 40–55 | 🔴 Moderate-Low |
| <40 | ⚫ High Risk |

## Radar Chart

Every report includes a pentagon radar chart generated by `scripts/radar_chart.py`:

```bash
python3 .claude/skills/company-health-eval/scripts/radar_chart.py \
  --data /tmp/radar_input.json \
  --output docs/examples/<company>_health_radar.png
```

All chart labels are in English to avoid CJK font rendering issues. Requires `matplotlib`.

## How It Works

This repository is designed to be operated by Claude Code via the `company-health-eval` skill. Each evaluation follows a linear pipeline:

1. **Parallel research** — Five Explore subagents search company fundamentals, financials, employee data, competitors, and risk factors simultaneously.
2. **Five-dimension scoring** — Each dimension scored 0–100 per the rubric, weighted into a composite score.
3. **Radar chart generation** — A Python script renders the pentagon chart with the composite score badge at center.
4. **Report writing** — Structured Chinese report covering: company profile, scored analysis, peer benchmarking, risk register, and career recommendations.
5. **Commit & push** — Every completed report is committed immediately.
