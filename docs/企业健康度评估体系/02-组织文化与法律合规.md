# 02 — 组织文化与法律合规

## 一、管理团队评估

### 1.1 管理层背景查询渠道

| 渠道 | 覆盖信息 | 使用要点 |
|------|----------|----------|
| **企查查/天眼查** | 高管名单、任职企业、关联方、变更记录 | 重点关注高管曾任职企业的退出原因（注销/吊销/失信） |
| **领英 (LinkedIn)** | 职业履历、教育背景、技能认证 | 验证工作年限衔接是否合理 |
| **脉脉** | 实名+匿名职场动态 | 搜索高管姓名可看到关联公司及认证信息 |
| **新闻报道** | 36氪、虎嗅、晚点LatePost | 交叉验证创始人公开言论与实际经营数据 |

### 1.2 创始人/CEO 评估维度

**行业经验：**
- 是否在该领域有 5 年以上深耕经历
- 过往履历是否与当前创业方向有逻辑关联
- 技术背景 vs 商业背景出身的创始人，对公司基因有决定性影响

**过往创业成败：**
- 企查查中"历史担任法定代表人"的企业生存状态
- 若有关联企业被吊销/列入异常，需重点核实原因
- 连续创业者 > 首次创业者（抗风险能力更强）

**公众言论与价值观：**
- 公开采访是否理性务实
- 🚩 过度承诺、夸大融资额、贬低竞对 → 红旗信号

**更换频率：**
- 同一职位 3 年内更换超过 2 次 → 高风险信号
- 联合创始人退出比例 > 30% → 需警惕

### 1.3 核心团队稳定性

| 指标 | 正常范围 | 预警信号 |
|------|----------|----------|
| CTO/技术VP任职时长 | 2年以上 | 1年内更换或频繁更换 |
| 技术骨干离职率（年） | <15% | >25%或关键模块负责人批量离职 |
| 高管离职集中度 | 均匀分布 | 3个月内多名VP级离职 |
| 工号段变化 | 稳步增长 | 批量招人又批量裁人 |

### 1.4 股权结构

- 企查查"股权穿透"查看最终受益人
- 创始人持股 < 30% → 存在控制权风险
- VIE架构公司需看WFOE层面，非仅看境内运营实体
- 🚩 创始人无投票权优势 + 机构股东占董事会多数 = 管理团队缺乏经营自主权

## 二、企业文化与员工口碑

### 2.1 脉脉使用技巧

- 搜索 `公司名 + 部门名` 定位具体团队
- 匿名区切换"最新"排序可看到未被水军覆盖的评价
- 关注匿名发言的"认证标识"（公司邮箱认证）
- 🚩 负面评价过于笼统 / 正面评价大量重复关键词 → 疑似水军
- 批量负面通常发生在裁员、降薪、期权暴雷之后，此时可信度极高

### 2.2 多平台评价甄别

| 平台 | 优点 | 陷阱 | 甄别方法 |
|------|------|------|----------|
| **看准网** | 结构化评分（薪资、面试、评价） | 企业公关删帖 | 看"面试评价"比"公司评价"更真实 |
| **知乎** | 长篇深度分析多 | "如何评价XX公司"下可能有公关文 | 关注回答者是否列出具体细节（日期、金额、人名） |
| **小红书** | 真实员工日常分享 | 容易成为招聘引流内容 | 看主页是否只发一家公司相关内容 |
| **Glassdoor** | 外企中国区评价 | 国内覆盖率低 | 关注中国区分部独立评分（常与全球评分差异大） |

### 2.3 "文化洗脑" vs 真实文化 识别信号

| 洗脑信号 | 健康信号 |
|----------|----------|
| 过度强调"奋斗""感恩""家文化"但福利低于市场中位 | 员工敢于在内部匿名吐槽而不被追查 |
| 强制参加文化培训/团建且占用休息日 | OKR/KPI目标合理，非拍脑袋定 |
| 淘汰率高的末位淘汰制度 | 管理层和一线员工办公条件无显著等级差异 |
| 大量内部宣传物料但员工福利差 | 离职员工仍愿意推荐朋友加入 |

### 2.4 996/内卷文化的识别信号

| 维度 | 预警信号 |
|------|----------|
| 招聘信息 | JD写"抗压能力强""能接受弹性工作时间""有创业精神" |
| 加班制度 | "弹性工作制"但实际要求早9晚9 |
| 考勤记录 | 脉脉上吐槽打卡时间超过12小时 |
| 周日会议 | 周日下午开周会 → 默认大小周 |
| 指标增长 | 每年目标翻倍但人数不增加 |
| 面试时间 | 面试安排在晚上8点后 → 加班是常态 |

## 三、法律合规风险

### 3.1 劳动仲裁与劳动争议查询

| 查询平台 | 操作路径 |
|----------|---------|
| **企查查/天眼查** | 搜索公司名 → 法律诉讼 → 筛选"劳动争议"分类 |
| **中国裁判文书网** | 输入公司名 + "劳动合同" |

**解读规则：**
- 劳动争议案件数量超过同规模公司 3 倍 → 异常
- 单个自然年内劳动争议激增 → 大概率发生过批量裁员
- 案由集中在"违法解除劳动合同"而非"经济补偿金争议" → 公司合规意识弱

### 3.2 行政处罚查询

| 处罚类型 | 查询渠道 | 严重程度 |
|----------|----------|---------|
| 工商处罚（虚假宣传、超范围经营） | 企查查/国家企业信用信息公示系统 | 中 |
| 环保处罚 | 企查查 + 当地生态环境局官网 | 高（制造业） |
| 税务处罚（偷漏税、虚开发票） | 企查查 + 税务局公告 | 极高 |
| 劳动监察处罚（欠薪、社保违规） | 企查查 + 人社局公示 | 高 |

### 3.3 重大诉讼关注点

- **股权纠纷** → 股东矛盾，公司治理有隐患
- **知识产权纠纷** → 公司是否侵犯他人专利/商标/著作权
- **合同纠纷（大额）** → 供应商/客户起诉，商业模式或履约能力问题
- **被执行信息** → "被执行人"或"失信被执行人"是最高级别警示

### 3.4 行业监管风险评级

| 行业 | 风险等级 | 主要风险点 |
|------|---------|-----------|
| 教培（K12） | 极高 | 双减后牌照审核极严 |
| P2P/互联网金融 | 极高 | 备案要求、非法集资风险 |
| 加密货币/Web3 | 高 | 政策模糊，交易所和矿场在国内不合法 |
| 游戏 | 中高 | 版号审批、未成年人保护 |
| 医疗健康 | 中高 | 广告法合规、医疗器械资质 |
| 跨境电商 | 中 | 税务合规、数据跨境传输 |
| SaaS/企业服务 | 低 | 主要关注数据安全和隐私合规 |

### 3.5 社保公积金缴纳合规

| 级别 | 做法 | 判断 |
|------|------|------|
| 合规 | 按实际工资基数缴纳，公积金5%-12% | ✅ 优质公司 |
| 灰色 | 按最低基数缴纳 | ⚠️ 常见于初创公司 |
| 违规 | 不缴纳或试用期不给交 | 🚩 违法行为 |

**面试核查话术**："公积金是按什么基数缴纳的？比例是多少？" 
正常范围：公积金合计10%-24%（个人+公司），低于10%需警惕。

## 四、中国劳动法核心权益

### 4.1 劳动合同红线

| 项目 | 法律规定 | 🚩 红线 |
|------|----------|--------|
| 签订时限 | 入职后1个月内 | 超过1个月未签，公司需支付双倍工资 |
| 必备条款 | 工资、工作地点、工作时间、岗位 | 空白工资条款（"具体金额见薪资确认单"） |
| 竞业限制 | 最长2年，须有补偿 | 无限扩大范围+无补偿 |
| 社保 | 必须缴纳 | "员工自愿放弃社保"条款无效 |

### 4.2 试用期规定

| 合同期限 | 最长试用期 | 试用期工资下限 |
|----------|-----------|---------------|
| 3个月以上不满1年 | 1个月 | 正式工资80% |
| 1年以上不满3年 | 2个月 | 正式工资80% |
| 3年以上/无固定期限 | 6个月 | 正式工资80% |

> 同一用人单位与同一劳动者只能约定**一次**试用期。

### 4.3 竞业限制合理性判断

| 维度 | 合理 | 🚩 不合理 |
|------|------|----------|
| 限制范围 | 具体列举的竞争对手 | "任何与本公司有竞争关系的企业" |
| 限制期限 | 最长2年 | 超过2年 |
| 补偿标准 | ≥离职前12月均工资的30% | 无补偿或仅象征性补偿 |
| 适用人员 | 高管、高级技术人员、保密人员 | 全员签署 |

**实操建议**：入职前要求明确竞业限制补偿标准写入合同；离职时要求公司书面确认是否启动竞业限制。

### 4.4 裁员补偿速查

| 情形 | 法律依据 | 补偿标准 |
|------|----------|----------|
| 协商一致解除 | 第36条 | N（可协商高于N） |
| 不能胜任工作 | 第40条 | N+1 |
| 经济性裁员 | 第41条 | N+1 |
| 违法解除 | 第87条 | 2N |
| 合同到期不续签（公司） | 第46条 | N |

> **N** = 工作年限（不满半年算0.5，半年以上不满1年算1）
> **+1** = 代通知金（未提前30天通知）
> **月工资基数** = 离职前12个月平均工资，上限为当地社平工资3倍

### 4.5 经济性裁员合法条件

1. **实体条件**：破产重整 / 经营严重困难 / 转产重大技术革新
2. **程序条件**：
   - 提前30天向工会或全体职工说明
   - 听取工会或职工意见
   - 向劳动行政部门报告
3. 🚩 裁你后一周开始大量招人 → 假裁员，可主张2N

## 五、区域劳动监察特点

| 地区 | 执法力度 | 特点 |
|------|---------|------|
| **上海** | 强 | 法制化程度最高，仲裁流程规范，对2N支持率高 |
| **杭州** | 中偏强 | 2024年起加大互联网大厂加班稽查 |
| **苏州** | 中 | 对制造业工伤认定和社保缴纳关注多 |
| **南京** | 中 | 仲裁效率较高 |
| **宁波/无锡** | 中偏弱 | 对民营企业劳动监察力度偏轻 |

> [!tip] 仲裁地选择
> 劳动仲裁遵循"劳动合同履行地"优先。如果公司注册地在偏远地区但实际办公在一线城市，应选择**办公所在地**仲裁。
