# 05 — 综合决策框架

## 一、多维度评分模型

### 1.1 评分表

对每个目标公司，从以下六个维度打分（1-5分），乘权重后加总：

| 维度 | 权重 | 评估要点 | 评分(1-5) |
|------|------|---------|-----------|
| 财务健康度 | 20% | 融资/上市状态、营收增长、现金流、社保人数趋势 | |
| 市场竞争力 | 15% | 行业排名、市场份额、技术壁垒、品牌影响力 | |
| 团队与文化 | 15% | 面试感受、员工口碑、管理层可信度、团队稳定性 | |
| 薪酬与福利 | 20% | 总包金额、公积金缴纳、福利完整性、期权价值 | |
| 个人发展 | 15% | 晋升空间、学习机会、技术成长、项目含金量 | |
| 区域因素 | 15% | 落户概率、生活成本、通勤、城市发展前景 | |
| **加权总分** | **100%** | | **/5** |

### 1.2 评分标准

| 分数 | 含义 |
|------|------|
| 5 | 行业标杆，几乎无可挑剔 |
| 4 | 明显优于大多数同行 |
| 3 | 行业中位水平，可接受 |
| 2 | 低于行业平均，需关注 |
| 1 | 严重问题，规避 |

### 1.3 决策阈值

- **总分 > 4.0**：优质选择，可优先考虑
- **总分 3.5-4.0**：可接受，权衡trade-off
- **总分 3.0-3.5**：有风险，需针对低分维度深入了解
- **总分 < 3.0**：建议规避

> 任一维度得分为1 → 即使总分高也需极度谨慎（如：薪酬满分但法律风险极高）

### 1.4 使用示例

| 维度 | 公司A（字节跳动） | 公司B（某B轮AI创业公司） | 公司C（某外资药企） |
|------|------------------|------------------------|-------------------|
| 财务健康度 | 5 | 2 | 4 |
| 市场竞争力 | 5 | 3 | 4 |
| 团队与文化 | 3 | 4 | 4 |
| 薪酬与福利 | 4 | 3 | 4 |
| 个人发展 | 4 | 5 | 3 |
| 区域因素 | 4 | 3 | 4 |
| **加权总分** | **4.15** | **3.25** | **3.85** |

## 二、不同人生阶段策略

### 2.1 应届生 / 毕业1-2年

**核心优先级**：平台 > 城市 > 薪资

| 推荐策略 | 理由 |
|----------|------|
| 优先选择上海/杭州等产业高地 | 第一份工作的平台效应远超薪资差距 |
| 优先大厂/知名外企 | 积累品牌背书，建立行业人脉 |
| 利用应届生身份落户上海 | 错过窗口后成本极高 |
| 关注学习机会 > 短期薪资 | 前3年的成长速度决定后续天花板 |

**避坑提示：**
- 第一份工作避免选择过小的创业公司（除非创始人是行业大牛）
- 注意竞业限制条款——应届生可能不理解其长期影响

### 2.2 30岁前（3-8年经验）

**核心优先级**：业务增长 > 现金回报 > 平台

| 推荐策略 | 理由 |
|----------|------|
| 选择有期权潜力的成长期公司（B-C轮） | 这个阶段最该积累的是项目深度和行业人脉 |
| 可以接受适度风险换取成长速度 | 抗风险能力强，失败了可以重来 |
| 关注"你能做到什么级别" | 30岁前的职级决定了后续的天花板 |

**避坑提示：**
- 不要为了短期高薪去没有成长空间的公司
- 警惕"养老型"岗位——会降低你的市场竞争力

### 2.3 35岁+（8-15年经验）

**核心优先级**：稳定性 > 成长性 > 现金回报

| 推荐策略 | 理由 |
|----------|------|
| 评估公司抗周期能力 | 核心看"公司是否赚钱"和"自己是否不可或缺" |
| 优先成熟上市公司/外企 | 稳定性高，裁员通常有补偿 |
| 苏州/无锡/宁波性价比上升 | 生活成本低，制造业外企多 |

**避坑提示：**
- 避免频繁跳槽——每一段经历应至少2-3年
- 关注公司对"大龄员工"的真实态度（脉脉上搜"35岁""优化"）
- 考虑管理路线 vs 专家路线的长期差异

### 2.4 已婚有娃

**核心优先级**：教育配套 > 通勤 > 薪资

| 推荐策略 | 理由 |
|----------|------|
| 优先南京（教育资源）或苏州（综合平衡） | 学区房/国际学校成为硬约束 |
| 上海教育优势显著但购房门槛最高 | 需权衡经济能力 |
| 关注公司的补充医疗保险（含家人） | 家庭保障需求上升 |

## 三、不同风险偏好策略

### 3.1 极度保守型

**适合**：有房贷/家庭负担重/临近退休

**推荐路径**：
1. 国企/央企/公务员
2. 头部外企（微软、SAP、西门子等）
3. 成熟大厂（阿里/腾讯/字节等）
4. 行业第二梯队龙头企业

**关键考察点**：
- 社保公积金是否全额缴纳
- 裁员政策（是否有明确的末位淘汰）
- 是否有企业年金

### 3.2 平衡型

**适合**：有一定积蓄/可以承受半年失业期

**推荐路径**：
1. 细分行业龙头（隐形冠军）
2. 快速成长的独角兽（C轮后）
3. 外企中国分部

**关键考察点**：
- 公司是否在扩招（招聘岗位数量）
- 是否在行业上行周期
- 期权是否有真实退出预期

### 3.3 风险偏好型

**适合**：年轻/有积蓄/无家庭负担/相信赛道

**推荐路径**：
1. A-B轮创业公司
2. 大厂内部创业部门
3. 新技术赛道（AI、Web3等）

**关键考察点**：
- 期权条款（回购机制、离职处理）
- 创始团队的行业履历和过往创业成绩
- 投资方背景和后续融资能力

## 四、面试反向考察问题库

### HR轮

- [ ] 薪酬结构是12薪还是14薪？绩效奖金占比多少？
- [ ] 五险一金是否按实际工资全额缴纳？公积金比例是多少？
- [ ] 试用期多长？试用期薪资是80%还是100%？
- [ ] 年假多少天？病假是带薪的吗？
- [ ] 晋升周期多长？是否有明确的评级体系？
- [ ] 年度调薪幅度一般在多少？是否有普调？

### 直属领导轮

- [ ] 团队现在有多少人？过去半年有几个人离职？
- [ ] 团队一般几点下班？周末是否需要处理工作？
- [ ] 你希望我在前三个月达成什么目标？
- [ ] 你觉得这个团队最大的挑战是什么？
- [ ] 为什么选择当前的技术栈/业务方向？
- [ ] 部门的营收/用户增长目标是多少？完成情况如何？

### 交叉面试/同事轮

- [ ] 你和这个岗位的团队如何协作？流程顺畅吗？
- [ ] 你在这个公司最让你惊喜的是什么？最失望的是什么？
- [ ] 公司的战略目标如何传递到一线？

### 面试后验证清单

- [ ] 面试中提到的人数规模 → 国家企业信用信息公示系统查社保人数
- [ ] 面试中提到的融资情况 → IT桔子/36氪验证
- [ ] 面试中提到的业务数据 → 行业报告交叉验证
- [ ] 口头承诺（发展空间、期权等）→ 要求写入offer
- [ ] 面试中观察到的异常 → 脉脉/知乎找离职员工验证

## 五、终极检查清单

### 投递前

- [ ] 确定2-3个目标城市（参考[[04-区域因素与信息渠道]]）
- [ ] 列出目标行业和公司清单
- [ ] 天眼查/企查查初筛（排除经营异常、失信名单）
- [ ] 排除红旗公司（大量劳动仲裁、社保人数骤降）

### 面试前（每家公司）

- [ ] 深度财务/融资分析（参考[[01-财务健康与市场竞争力]]）
- [ ] 员工口碑调研（脉脉、知乎、看准网）
- [ ] 行业地位与增长前景判断
- [ ] 准备反向考察问题（见上节）

### 面试中

- [ ] 观察办公环境、员工状态、面试官态度
- [ ] 向HR确认薪酬结构与福利细节
- [ ] 向直属领导了解团队真实状况
- [ ] 记录所有关键信息

### Offer阶段

- [ ] 用评分模型横向对比多个offer
- [ ] 验证面试中获取的信息
- [ ] 咨询行业前辈/校友
- [ ] 结合人生阶段策略做出最终决策

## 核心原则（重申）

1. **信息交叉验证**：单一来源不可信，至少3个独立来源
2. **现金流优先于利润**：对于上市公司，经营现金流比净利润更重要
3. **社保人数最诚实**：国家企业信用信息公示系统的社保缴纳人数，比任何PR稿都真实
4. **期权按零估值**：除非Pre-IPO且有明确上市时间表
5. **没有完美公司**：关键是明确你当前阶段的优先级
