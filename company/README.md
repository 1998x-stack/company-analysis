## 设计原则

- **务实优先**：以公司实际主营业务归类，而非注册行业。例如迈富时注册为「软件服务」但实质是营销SaaS。
- **可扩展**：未来新增公司时，若现有二级行业不匹配，新增二级目录即可；若一级行业不匹配，新增一级目录。
- **参考申万行业分类**：一级行业参考申万2021版分类标准，但做了精简和本地化调整（如「互动娱乐」替代「传媒」）。

## 文件组织

每个公司文件夹内包含：
- `*财务健康评估-YYYY-MM-DD.md` → 软链接到 `docs/examples/`
- `*_health_radar.png` → 软链接到 `docs/examples/`

所有文件实体统一存放在 `docs/examples/`，`company/` 目录仅做分类索引和软链接映射。

软链接由 `company-health-eval` skill 在生成报告时自动创建（见 `.claude/skills/company-health-eval/SKILL.md` 阶段八）。手动补充归档时，相对路径固定为 `../../../../docs/examples/`。

详见 [index.md](index.md) 获取公司评估总览与得分排名。
