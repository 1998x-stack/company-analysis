# 01 — 财务健康与市场竞争力

## 一、财务健康度分析

> [!tip] 使用技巧

### 1.2 关键财务指标解读

#### 成长性指标

| 指标 | 健康标准 | 预警值 |
|------|---------|--------|
| 营收增长率 | 连续3年 > 15% | 连续下滑或负增长 |
| 归母净利润增长率 | 与营收增速匹配 | 营收增但利润降（增收不增利） |
| 扣非净利润 | 与净利润接近 | 差异过大（>20%）说明盈利质量差 |

#### 盈利质量指标

| 指标 | 优秀 | 良好 | 预警 |
|------|------|------|------|
| 毛利率 | 软件>70% | 制造20-30% | 持续下降 |
| ROE（净资产收益率） | >20% | >15% | <5% |
| ROA（总资产收益率） | >8% | >5% | <2% |

#### 现金流指标（最关键）

> [!warning] 核心原则
> **利润是观点，现金流是事实。** 许多爆雷公司在出事前净利润尚可，但经营性现金流已连续多年为负。

- **经营性现金流净额**：连续为正且覆盖净利润为健康
- **自由现金流**：持续为正为佳；持续为负则需融资维持运营
- **净现比**（经营现金流/净利润）：>1 为优秀，<0.5 需警惕

#### 偿债能力指标

| 指标 | 安全范围 | 预警范围 |
|------|---------|---------|
| 资产负债率 | <60% | >70% |
| 流动比率 | >1.5 | <1 |
| 速动比率 | >1 | <0.5 |
| 利息保障倍数 | >3 | <1.5 |

### 1.3 非上市公司评估

#### 融资轮次分析

| 轮次 | 特征 | 风险评估 |
|------|------|---------|
| 种子/天使轮 | 产品未上线或初版 | 极高风险，主要看创始人背景 |
| A轮 | 产品上线，初步验证PMF | 高风险，看产品市场匹配度 |
| B轮 | 商业模式初步验证 | 中高风险，看规模化能力 |
| C轮+ | 有一定市场份额 | 中等风险，关注对赌协议 |
| Pre-IPO | 相对成熟，上市预期明确 | 中低风险 |

#### 投资方背景判断

- **头部VC**（红杉、IDG、高瓴、启明、经纬）：经过严格尽调，背书价值高
- **国家队基金**（国投、中金、地方产业基金）：符合政策方向
- **产业资本**（腾讯、阿里、字节战略投资）：有业务协同价值
- **🚩 红旗信号**：频繁更换投资方、老股东折价退出、创始人股权被大幅稀释

> [!tip] 查询渠道
> - **IT桔子** (itjuzi.com)：融资轮次、金额、投资方
> - **企查查/天眼查**：股权穿透、注册资本实缴情况
> - **36氪/虎嗅**：深度融资报道

### 1.4 财务风险信号清单

| 风险信号 | 表现 | 严重程度 |
|----------|------|---------|
| 持续亏损 | 连续3年扣非净利润为负 | ★★★★ |
| 大额商誉 | 商誉占净资产>30%且并购不达预期 | ★★★★ |
| 高股权质押 | 实控人质押比例>80% | ★★★☆ |
| 频繁换审计 | 3年换2次以上会计师事务所 | ★★★★★ |
| 存贷双高 | 账面大额现金+高额有息负债 | ★★★★★ |
| 高管频繁离职 | 财务总监/董秘/独董异常离职 | ★★★☆ |
| 监管问询 | 交易所多次发问询函 | ★★★☆ |
| 社保人数骤降 | 年度社保缴纳人数大幅减少 | ★★★★ |

## 二、市场竞争分析

### 2.1 行业地位判断

- **市场份额**：通过行业报告（艾瑞、IDC、Gartner）、上市公司年报、券商研报获取排名
- **招标数据**：剑鱼标讯、千里马招标查实际业务获取能力
- **品牌影响力**：行业榜单（财富500强、胡润榜）、脉脉/看准网雇主口碑

### 2.2 竞争壁垒评估框架

| 壁垒类型 | 判断方法 | 可复制难度 |
|----------|---------|-----------|
| 技术壁垒 | 专利数量、研发投入占比、核心技术来源 | 高（3-10年） |
| 牌照/资质壁垒 | 金融牌照、医疗器械注册证等 | 极高（政策门槛） |
| 渠道壁垒 | 经销商网络、KA客户关系 | 中高（2-5年） |
| 品牌壁垒 | 消费者认知、品牌溢价能力 | 高（5-10年） |
| 规模壁垒 | 单位成本优势、网络效应 | 中（1-3年） |
| 数据壁垒 | 用户数据量级、数据获取排他性 | 中高（2-5年） |

> [!important] 核心逻辑
> 真正的壁垒应难以在**3年内**被复制。依赖单一个人技术的所谓"壁垒"是伪壁垒。

### 2.3 增长潜力分析

- **行业生命周期**：成长期 > 导入期 > 成熟期 > 衰退期
- **行业增速**：CAGR > 20% 为高速赛道
- **公司 vs 行业增速对比**：持续跑赢行业 = 有阿尔法（超额增长能力）
- **研发投入**：科技公司研发费用率 > 10% 为重视研发
- **人均产出**：持续提升说明效率改善
- **在手订单/预收款**：反映未来收入确定性

## 三、上海/江浙沪产业地图

### 3.1 各城市优势产业与代表公司

| 城市 | 核心产业 | 代表性公司 |
|------|----------|-----------|
| **上海** | 金融、外资总部、生物医药、集成电路、AI | 拼多多、小红书、米哈游、药明康德、中芯国际、特斯拉、B站 |
| **杭州** | 电商、互联网、AI、金融科技、数字安防 | 阿里巴巴、蚂蚁集团、网易、海康威视、大华股份、字节(杭州) |
| **苏州** | 高端制造、半导体、生物医药(BioBay) | 信达生物、恒力集团、博世、三星、罗氏诊断 |
| **南京** | 软件信息、教育科研、新能源汽车 | 华为南研所、中兴南京、迈瑞南京、福特 |
| **无锡** | 集成电路、物联网、光伏 | SK海力士、药明康德(总部)、华润微电子、先导智能 |
| **宁波** | 港口物流、智能制造、汽车零部件 | 均胜电子、舜宇光学、宁波银行、申洲国际 |

### 3.2 区域政策关键词

- **长三角一体化**：产业协同、交通一体化、公共服务互通
- **上海自贸区及临港新片区**：金融开放、跨境贸易、特殊落户政策
- **G60科创走廊**：沿沪嘉杭高速的科技创新带
- **科创板**：上交所服务硬科技企业，利好半导体/生物医药/AI公司
- **合肥模式**：以投带引培育产业集群（面板、存储、新能源）

### 3.3 求职策略速查

| 目标 | 首选城市 | 原因 |
|------|---------|------|
| 高薪+外企文化 | 上海 | 金融、咨询、外资区域总部密集 |
| 互联网+创业氛围 | 杭州 | 阿里系生态，AI/电商人才需求大 |
| 制造业+稳定发展 | 苏州/无锡/宁波 | 外企工厂和研发中心多，生活成本低 |
| 低成本+政策红利 | 合肥 | 新兴产业岗位快速增长，房价友好 |
| 宜居+高校资源 | 南京 | 高校密度全国第三，教育资源丰富 |

## 推荐尽调流程

1. **基础信息层（15分钟）**：天眼查/企查查 → 股权结构、诉讼风险、工商变更
2. **财务健康层（30分钟）**：上市公司查巨潮+东方财富；非上市公司查融资历史+投资人背景
3. **市场竞争力层（20分钟）**：行业报告、市场份额、竞争对手、技术壁垒
4. **雇主口碑层（15分钟）**：脉脉/看准网 → 员工评价、离职率、管理层风格
5. **新闻舆情层（10分钟）**：最新动态、负面新闻、行业政策变化
